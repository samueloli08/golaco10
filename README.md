# ⚽ Golaço 10

Um jogo interativo de futebol desenvolvido com o auxílio de Inteligência Artificial, unindo arquitetura orientada por prompts à validação e engenharia de software humana.

## 🤖 Como este projeto foi desenvolvido

Este projeto foi construído utilizando um fluxo de **Engenharia de Prompts** em conjunto com o **Claude** (Anthropic). 

Em vez de apenas gerar código de forma automática, o desenvolvimento seguiu um processo iterativo e supervisionado:
* **Direcionamento e Arquitetura:** Criação de prompts estruturados para definir as mecânicas do jogo, lógica de funcionamento e interface.
* **Revisão e Supervisão Técnica:** Análise crítica de cada trecho de código gerado pela IA para garantir organização, boas práticas e coerência com o objetivo do projeto.
* **Depuração e Correção de Erros:** Identificação manual de bugs, ajustes de lógica, tratamento de exceções e refinamento contínuo até atingir a versão funcional.
